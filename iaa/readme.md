## Inter-annotator agreement (IAA) calculations and results

* [nimeyksuste_koosk6la_2022-01-04.zip](nimeyksuste_koosk6la_2022-01-04.zip) -- [Brat](http://brat.nlplab.org/index.html) export files used for calculating IAA, and results of the IAA calculations. Notes: 

    * Data folder names are in Estonian, can be translated as follows: _margendaja1_ => _annotator1_, _margendaja2_ => _annotator2_, _yhisloome_ => _crowdsourced_annotations_ ;
    
    * NE tags are in Estonian, these were later translated/converted in the following way: _Isik_ => _PER_, _KO\_koht_ => LOC\_ORG, _Koht_ => _LOC_, _Org_ => _ORG_, _Muu_ & _Teadmata_ & _ese_ => _MISC_ ;

* [nimeyksuste_koosk6la_skriptid_2020-09-16.zip](nimeyksuste_koosk6la_skriptid_2020-09-16.zip) -- Python scripts that were used for calculating IAA. Requirements: [tabulate](https://pypi.org/project/tabulate/) and [bratiaa](https://pypi.org/project/bratiaa).
